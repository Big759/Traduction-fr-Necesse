# Traduction-fr-Necesse
Ce dépôt est une archive du fichier .lang pour le jeu [Necesse](https://store.steampowered.com/app/1169040/Necesse/), il contient la version originale ainsi que sa traduction en français. Cette archive est destinée à faciliter l'édition, mais aussi pour voir plus facilement les changements apportés.

## Règles à connaître
* Le jeu utilise généralement des termes neutres sauf en cas d'exception.
* En éditant le fichier de traduction vous pouvez le recharger directement depuis le jeu pour voir les modifications en utilisant la commande <code>/reloadlang</code>.
